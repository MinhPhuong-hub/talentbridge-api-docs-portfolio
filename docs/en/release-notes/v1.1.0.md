# TalentBridge API v1.1.0 release notes

Release date: October 24, 2026

Version 1.1.0 improves the job-application workflow and developer
documentation.

## Compatibility

The optional `coverLetter` field is backward compatible. Existing v1 clients do not need to migrate to use v1.1.0; adopting the field is optional. The documented duplicate-application `409 Conflict` response should be handled explicitly; it is described as part of this fictional version, not verified backend behavior.

## Optional cover letters

Candidates can now include an optional `coverLetter` property when
submitting an application.

Example:

```json
{
  "coverLetter": "I have three years of experience writing API documentation."
}
```

This change is backward compatible. Existing integrations are not
required to send the new field.

## Duplicate applications

Submitting a second application for the same candidate and job now
returns:

`409 Conflict`

Clients should treat this response as an indication that an application
already exists rather than retrying the same request automatically.

## Documentation improvements

This release also clarifies:

- authentication and authorization errors
- ownership requirements for viewing job applications
- pagination cursor behavior
- server-generated identifiers

## Action required

No migration is required for existing v1 clients.

Clients that want to support cover letters can add the optional
`coverLetter` property to their application request.
