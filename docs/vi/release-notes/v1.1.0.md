# Ghi chú phát hành TalentBridge API v1.1.0

**Ngày phát hành giả lập:** 24/10/2026

Phiên bản v1.1.0 cải thiện quy trình ứng tuyển và tài liệu dành cho nhà phát triển.

## Khả năng tương thích

Trường `coverLetter` không bắt buộc có tính tương thích ngược. Client v1 hiện tại không cần migration để sử dụng v1.1.0; việc gửi trường mới là tùy chọn. Client cần xử lý rõ phản hồi `409 Conflict` khi ứng tuyển trùng. Đây là hành vi được mô tả trong phiên bản giả lập, không phải kết quả kiểm chứng trên backend thực.

## Thư ứng tuyển không bắt buộc

Ứng viên có thể gửi thêm trường `coverLetter` (không bắt buộc) khi tạo hồ sơ ứng tuyển.

Ví dụ:

```json
{
  "coverLetter": "I have three years of experience writing API documentation."
}
```

Thay đổi này tương thích ngược: các client đang tích hợp không bắt buộc gửi trường mới.

## Hồ sơ ứng tuyển trùng lặp

Khi cùng một ứng viên nộp hồ sơ lần thứ hai vào cùng một việc làm, API trả về `409 Conflict`.

Client nên hiểu response này là dấu hiệu hồ sơ đã tồn tại, thay vì tự động gửi lại cùng một request.

## Cải thiện tài liệu

Bản phát hành cũng làm rõ:

- Sự khác biệt giữa lỗi xác thực và lỗi phân quyền.
- Quyền sở hữu khi xem danh sách hồ sơ ứng tuyển.
- Cách sử dụng cursor phân trang.
- Các mã định danh do server tạo.

## Hành động cần thực hiện

Client đang dùng v1 không cần migration cho bản v1.1.0. Nếu muốn hỗ trợ thư ứng tuyển, client có thể thêm trường `coverLetter` không bắt buộc vào request tạo hồ sơ.
